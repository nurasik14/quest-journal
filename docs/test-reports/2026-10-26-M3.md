## Bugs / findings (by severity)

No blocker, critical or high findings.

### LOW-1: The safety blocklist rejects harmless phrases ("Tea drunk")
- **Repro:** the fake model returns a valid day whose `done_when` is "Tea drunk", then check in.
- **Expected:** AI day.
- **Actual:** `rules=safety:0` on both attempts, then a pool fallback with the "Claude couldn't be reached" banner. That wastes 2 calls (~20 s with real claude) for a harmless phrase. PROGRESS PROVISIONAL 25 says "wine-red" is also blocked.
- **Suspected file:** `server/src/domain.ts` `SAFETY_BLOCKLIST` (the bare `drunk`/`wine` alternatives). Consider limiting the check to `title`/`why`, or using phrase forms like "get drunk".

### LOW-2: Preempting a boss whose child ignores SIGTERM delays the check-in job by the full 5 s kill grace
- **Repro:** the boss call hangs with `trap '' TERM`. Open Today, then check in.
- **Expected:** "a hung boss never delays a check-in".
- **Actual:** `generate_boss attempt 1: preempted in 6015 ms`, and the day starts only after that. The check-in HTTP response itself is still fast (0.257 s). Real claude normally honours TERM, so the impact is small.
- **Suspected file:** `server/src/ai.ts` `terminate()`. On `aborted`, send SIGKILL to the process group at once, or settle the run promise on abort without waiting for exit.

### LOW-3: The coin live-region text repeats itself
- **Actual:** after marking a quest done, the header region reads "+10 Earned 10 silver taels earned today. Balance 20."
- **Expected:** e.g. "Earned 10 silver taels. Balance 20."
- **Suspected file:** the `CoinBadge` announce string, or how Today passes the caption. It may predate M3.

### LOW-4: An unknown reroll quest ID returns 404, but G15 lists `not_found` among the 409s
- **Actual:** `POST /api/quests/2026-10-27-9/reroll` → `404 {"code":"not_found"}`.
- 404 is arguably more correct. Fix either the AC text or the code so they agree (`server/src/today.ts`).

### LOW-5: The init commit gets mislabelled "(+hand edits)" when the first write lands inside the debounce window
- **Actual:** `qj: init, boss 2026-W44 pool, boss 2026-W44 ai, checkin 2026-10-27 (+hand edits)`. The seeded `quests.yaml`, `rewards.yaml` and `kb/*` are counted as hand edits.
- **Suspected files:** `server/src/init.ts` / `git.ts` (the init reason has no file list). This is not new M3 code, but M3's earlier boss and check-in writes make it more likely.

### LOW-6: `HerbLoader` ignores the `[data-motion=reduce]` override
- **Actual:** `tokens.css` supports both the media query and `:root[data-motion=reduce]`. `HerbLoader.svelte:147` only stops the grind, flake and dots animations under `@media (prefers-reduced-motion: reduce)`.
- **Suspected file:** `web/src/lib/theme/HerbLoader.svelte`.

### Nits
- **N1:** The "Try again" helper reads "The apothecary can try again from its own shelf." But Try again calls Claude first and only then the shelf.
- **N2:** The loader heading shows "grinding herbs……", because the `…` in the copy is followed by the animated `···`.
- **N3:** A `too_long` reroll with a pool fallback can pick "Study for an hour at a café…" (pool quests have no `minutes`, so the rule can't apply).
- **N4:** At 390 px, the 412 toast still overlaps the red save bar for 4 s (already a known gap in PROGRESS).
