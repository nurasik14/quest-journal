### MED-1: Notes 412 actions are not full-width on a phone (H1-7 AC3 FAIL)
- **Repro:** 390×844 → Notes → Profile tab → Edit → type something → change `kb/profile.md` on disk → Save.
- **Expected:** at ≤ 400 px, "Copy my text" (primary), "Load the newer page" and "Save mine anyway" are stacked **full-width** under the heading.
- **Actual:** the heading takes the left side and the buttons sit in an **80 px** column on the right (x=277): `80x44`, `80x64`, `80x48`. "Load the newer page" breaks onto 4 lines (`H1t-19-notes-412-390.png`). At 1280 it's the same side-by-side split, but it reads fine there (`H1t-19-notes-412-1280.png`).
- **Suspected file:** `web/src/lib/components/NotesEditor.svelte`. `.stale` also has the `qj-banner` class, whose `display:flex` defaults to a row. Add `.stale { flex-direction: column; align-items: stretch; }` (or `display:block`).
- **Test gap:** the source test checks the CSS rule, not the rendered width. The builder's smoke measured only the panel top.

### LOW-1: a "too long" swap can still return a long quest (#124 intent)
- **Repro:** fresh copy, fake `ok` → check-in energy 3 → set the fake to `exit3` (so the pool path runs) → `POST /api/quests/2026-10-26-2/reroll {"reason":"too_long"}` on "Sketch one object on your desk" (30 min).
- **Expected:** a shorter replacement, or an honest failure.
- **Actual:** "Do 4 Pomodoros (25/5) on the course you're avoiding most", about 2 hours.
- **Other long entries:** "Spend an afternoon exploring a district you've never been to" also passes the filter, and `mentionedMinutes("Watch a 2h film")` → null.
- **Suspected files:** `server/src/fallback.ts` (`mentionedMinutes` only knows literal hour/minute words) and the seed pool `docs/brainstorm/seed/quests.yaml`, which has no `minutes:` fields even though they're now supported.
- **Suggested fix:** give the long entries `minutes:` (pomodoro ×4 = 120, afternoon ≥ 180, a 2-hour block = 120) and/or recognise `\d+h`, "pomodoro", "afternoon" and "evening" as long.

### LOW-2: `fitsTooLong` skips the text rule when only the candidate has `minutes`
- **Repro (pure):** `fitsTooLong({title:"Study for an hour", why:"", minutes:60}, undefined)` → `true`. With `minutes:90` and "Deep clean the flat" it's also `true`.
- **Expected (AC H1-11.2):** compare minutes only when **both** are known. Otherwise a title or why that mentions hours (or ≥ 10 min) excludes the candidate.
- **Suspected file:** `server/src/fallback.ts` l.237–241. When `rejectedMinutes` is undefined, fall through to the text check (or treat `q.minutes ≥ 10` as too long).
- **Impact today:** none with the seed pool (no `minutes:`). It only shows up once someone adds `minutes` by hand, which LOW-1's fix would do.

### NIT-1: cooldown buy sheet still says "Balance after"
- The café-meal sheet after a purchase reads "Balance after: 1,550 | Available again on Saturday. | Save toward this | Close". A balance-after line for a purchase that can't happen is a small false promise.
- Hide it in `save` mode (`web/src/routes/Market.svelte`).

### NIT-2: two stories at once on a timed-out mutation
- At the 20 s timeout, the global banner "Couldn't reach the apothecary. Nothing was lost. Try again in a moment." appears in the same instant as the toast "The laptop didn't answer in time. It may not have saved; try again." In my repro the change **had** been saved.
- The banner clears on the next successful request.
- **Suggested fix:** don't call `onReach(false)` for a mutation `TimeoutError` (`web/src/lib/http.ts`), or use banner copy that doesn't imply nothing happened.

### NIT-3: `infoDismissed` memory fallback loses to stale storage
- `getInfoDismissed()` returns `localStorage.getItem(...) ?? memory`. If `setItem` throws (quota) while an older value is stored, yesterday's key wins and today's dismissed line comes back on the next render/reload.
- **Suggested fix:** prefer `memory` when it's set (`web/src/lib/infoDismissed.ts`).
