## Bugs (by severity)

No HIGH or MED bugs.

### LOW-3: a too_long swap can still be longer, because the rejected quest's length is inflated by incidental words (left over from LOW-1)
- **Repro (live):**
  1. Fresh copy of `s1`, with the fake set to `exit3` so the pool path runs.
  2. `POST /api/today/checkin {"energy":3}`.
  3. `POST /api/quests/2026-10-26-3/reroll {"reason":"too_long"}` on "Ask one question in a lecture or at office hours" (seed `minutes: 5`).

  The UI gives the same result: Today → Swap → "Too long".
- **Expected:** a strictly shorter medium quest, or the honest "This one stays."
- **Actual:** "Write a 300-word scene in the style of a court-mystery manga" (`minutes: 40`), with `rerolls_used: 1`.
- **Root cause:** `estimateMinutes(target)` = max(field 5, text). The bare `\bhours?\b` rule matches "office **hours**" → 60, so every candidate under 60 min fits.
- **Pure repro of the same cause:** "Stretch for 10 minutes between two study blocks" (`minutes: 10`) has a why containing "all **day**", which reads as 480. Rejecting it as too long picked 15–20 min quests on 4 dates.
- **Seed entries whose estimate disagrees with their field:**
  - stretch: 10 → 480;
  - office hours: 5 → 60;
  - golden hour: 45 → 60 (harmless, since it errs on the long side).
- **The AI path has it too:** `validateReroll` uses the same `rejected.minutes`, so an AI swap that's longer than the real quest is also accepted.
- **Suspected files:** `server/src/generation.ts` (`rejectedMinutes = estimateMinutes(target)`) and `server/src/fallback.ts` (`mentionedMinutes`).
- **Suggested fix:**
  - For the **rejected** quest, use its explicit `minutes` when present, and fall back to the text only when it's missing. Keep max() for **candidates**, where overestimating is the safe direction.
  - Optionally, drop "hours" when it follows "office", and ignore span words in the `why`.
- **Test gap:** the builder's exhaustive test seems to compare picks against `estimateMinutes`, which is the same inflated number. Compare against the seed `minutes` field instead.

### NIT-5: rough edges in `mentionedMinutes`
- "Read for half an hour" → 60, because the bare "hour" rule fires.
- Number words aren't parsed: "Stretch for ten minutes" → null, and "two hours of practice" → 60, only via the bare-hour rule.
- Low impact now that the seed carries `minutes:`. It matters only for quests added by hand without `minutes`.
