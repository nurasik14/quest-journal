## Bugs (ranked)

### NEW-LOW-1: the Evening badge goes stale when an evening save changes the economy, and that bonus never gets its toast
- **Repro:**
  1. Have 6 counting days and no quest done today (balance −30).
  2. Open `/evening`, tap rating 7, type notes, press "Seal today's ledger".
- **Expected:** the rating makes today count. That is the 7th consecutive day, so +25 bonus and +1 herb, and the true balance is −5. The Evening header badge should show −5 (AC16: "fed from every `{economy}` the API returns"), and the bonus moment should get its toast once (AC19).
- **Actual:**
  - `/api/economy` → `balance:-5, streak:7, bonus_today:25, freeze_tokens:1`.
  - The Evening badge still shows **−30** (unchanged after 5 s).
  - No bonus toast appears on Evening, and none later on Today: `bonusMoment` sees `bonus_today` already set when Today loads.
  - Navigating to Today shows the correct −5, with no delta.
- **Cause:** `PUT /api/days/:date/evening` returns `{day, reflect_job, reflect_skip}` with no `economy` (`server/src/app.ts:226-240`), so `lib/economy.svelte.ts` is never fed on this path. AC1 lists the routes that carry `economy` and doesn't list the evening save, so this is a gap in the spec more than a contract break.
- **Suggested fix:**
  - Include `economy` in the evening PUT response (and the backfill save), and feed the store from `Evening.svelte`.
  - Alternatively, have Evening re-fetch `/api/economy` after a save.
- **Severity: LOW.** Display only, self-corrects on navigation, no data or money effect.
